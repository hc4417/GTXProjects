# Project Overview

## Document Management System Prototype
The main prototype can be accessed via the Vue.js router path `/playground`. 

To view:
1. Clone the repo
2. Install dependencies:
```sh
npm install
```
3. Run the development server:
```sh
npm run dev
```
4. Open the app in your browser and navigate to the path `/playground`

## Other Project Components
Other folders contain exercises and practice projects used to familiarize myself with the Vue environment and related tools. These are included for context but are **not part of the main prototype**.
